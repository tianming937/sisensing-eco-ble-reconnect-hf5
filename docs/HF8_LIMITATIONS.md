# hf8-r2 已知限制和风险边界

## 当前状态

- 版本是 02.23.01.00-v16.1-hf8 / code46；公开附件限定为通过 MuMu FGS 修正测试的 r2。
- 只有模拟器、静态、重连模型、成品反编译和 DEX 结构检查结果；没有真实探头的 hf8 长时间数据。
- 因此它是测试预发布版；“方案针对根因”不能外推成“任何设备已永久修复”。

## 现实中仍可能失败的情形

- 探头在范围外、停止广播、没电、到寿命、损坏、被其他手机占用或与手机射频干扰。
- Android/Samsung 在后台限制扫描/前台服务；用户未解锁、撤销权限、通知/电池策略变化；OTA 后蓝牙栈行为变化。
- BLE 广播过滤器不匹配实际广播、SDK 不把系统扫描错误回调到新协调器、GATT 连接建立后未及时收到服务/有效数据。
- 新探头使用未适配算法。fail-closed 的预期是拒绝读数；这比输出猜测值安全，但仍会导致无数据。
- 冷却行为会让自动扫描暂缓 120/300 秒；不要把冷却期间的等待误判为进程已杀，也不要通过连续点击制造更多扫描请求。

## r1 不随发布，原因

r1 的 FGS 条件检查在 Android 12 上错误提前要求 Android 14 connectedDevice 权限，未能成功进入前台；粘性启动路径造成服务超时 ANR。该包被拒绝，不能安装/传播。r2 修正系统边界并经过 MuMu 复测。r2 仍需 API34+ 真机验证。
